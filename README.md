# Usthad Food Supply Tracker — College Dining Coordination & Analytics

A clean, role-based web application designed for coordinating college Usthads' food supply across all 5 daily meal timings, managing leave substitutions, and tracking team effort and punctuality.

## Included Files
- `index.html` — Complete standalone web application (ready to open directly in any browser or host on GitHub Pages / Firebase Hosting).
- `README.md` — Quick start guide and default credentials.

## Key Features
1. **5 Daily Food Timings**: Morning Tea (`6:00 AM`), Nasta (`8:25 AM`), Afternoon Lunch (`1:15 PM`), Evening Tea (`4:30 PM`), and Night Dinner.
2. **Sections & Leave Substitution Manager**: Tracks Main Section (8 Usthads), Second Section (25+ Usthads), Third Section (15+ Usthads), and the Extra Reserve Pool (Uvais & Aman), with instant leave toggling and substitute assignment.
3. **Leader Admin Edit Mode**: Toggle **Admin Edit** in the header to edit supplier names, bonus points, section counts, or meal timings anywhere.
4. **Effort & Shared Tea Analytics**: Ranks suppliers by duty completion, early arrival speed, and Morning/Evening tea & glass washing participation.
