# Usthad Food Supply Tracker — Smart Dining, Attendance & Verification Suite (v3)

A responsive, mobile-first web application designed for coordinating college Usthads' food supply across all 5 daily meal timings, managing monthly attendance with a calendar, handling leave substitutions, and verifying team effort.

## Included Files
- `index.html` — Complete standalone web application (open directly in any browser or deploy to GitHub Pages / Firebase Hosting).
- `README.md` — Setup guide, login details, and workflow overview.

## Key Features
1. **Two-Step Tick & Leader Verification Workflow**: Suppliers tick their own duties (`Awaiting Verify` badge), and Leader Sinan verifies individual cards or uses **Verify All Ticked Duties for Meal**. Only verified tasks count toward leaderboard scores.
2. **Monthly Attendance Calendar**: Interactive monthly calendar showing daily Present (`P`), Late (`L`), and Absent/Leave (`A`) counts with daily roll-call verification and monthly summaries.
3. **Filtered "On Behalf Of" Substitution**: When reassigning a supplier on behalf of someone else, the dropdown automatically filters to uncovered leave members and available active colleagues.
4. **Mobile-First UI/UX**: Includes quick-tap supplier login chips, password visibility toggle, sticky bottom navigation bar on mobile, and live pending-verification indicators.
